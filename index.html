Installation guide

Android

1. Download the APK.
2. Open the downloaded file.
3. Follow Android's installation prompts. Only allow installation if you trust the source.
4. Open Math Engine.

Windows

1. Download the EXE installer.
2. Open it and follow the setup wizard.
3. Open Math Engine from the installed application.

Linux (Debian / Ubuntu)

1. Download the DEB file.
2. Open Terminal in the Downloads folder and run:
sudo apt install ./math-engine_1.0.1_amd64.deb
3. Launch Math Engine from your applications menu.

iPhone / iPad

Native iOS installer is not currently available.
